# Parsen website

Static website for `dev.parsen.no`.

## Files

- `index.html` — site pages, layout, content, and client-side navigation
- `.htaccess` — Apache rewrite rules for the page URLs

The site is currently published to Gigahost at:

`/domains/dev.parsen.no/public_html`

## Local preview

Run a local static server from this folder, or open `index.html` directly in a browser.

## Editing

This package can be imported into Silex as a starting point. After visual editing, export the generated files and keep `.htaccess` when publishing to Apache hosting.
